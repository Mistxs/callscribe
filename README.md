# CallScribe

Меню-бар приложение для macOS: записывает звонок или экран, локально расшифровывает речь в текст и складывает результат в папку. Без облака, без отправки аудио наружу.

## Что умеет

- **Запись звонка** — системный звук (то, что вы слышите в Zoom, Telegram, Meet, Slack и т. п.) плюс микрофон.
- **Запись экрана** — видео экрана (H.264) и системный звук плюс микрофон.
- **Локальная расшифровка** — Whisper large-v3 на Apple Neural Engine через [WhisperKit](https://github.com/argmaxinc/WhisperKit). Русский язык по умолчанию.
- **Автоматическая обработка** — после остановки запись сама превращается в `.txt`; при желании рядом сохраняется `.srt` с таймкодами.
- **Один файл для внешних сервисов** — обе дорожки (системный звук + микрофон) можно свести в один WAV.
- **Всё локально** — аудио, видео и текст не покидают Mac. Модель скачивается один раз с Hugging Face.

## Требования

- macOS 15 Sequoia или новее.
- Apple Silicon (M1/M2/M3/M4). Модель работает через Core ML / Neural Engine.
- 16 ГБ RAM желательно (large-v3 комфортно работает и на 8 ГБ, но при длинных записях запас памяти не помешает).
- ~1 ГБ свободного места на модель + место под записи.

## Установка

```bash
cd ~/callscribe
make app          # собрать dist/CallScribe.app
make install      # скопировать в /Applications и запустить
```

Или без установки:

```bash
make run
```

При первом запуске в строке меню появится иконка waveform. Приложение не показывает иконку в Dock — это нормально.

### Разрешения macOS

При первом запуске записи macOS попросит разрешения. Их можно выдать заранее:

1. **Системные настройки → Конфиденциальность и безопасность → Запись экрана** — включить `CallScribe`.
2. **Системные настройки → Конфиденциальность и безопасность → Микрофон** — включить `CallScribe`.
3. Перезапустить приложение (кнопка есть в настройках CallScribe).

Если `CallScribe` ещё нет в списке — это нормально: macOS добавляет приложение только после первого запроса доступа. Установите его в `/Applications` (`make install`), откройте настройки CallScribe и нажмите **«Разрешить»** рядом с «Запись экрана» — появится системный запрос, после которого приложение окажется в списке. Если запрос не появился, нажмите **«+»** в разделе «Запись экрана и системного звука» и выберите `/Applications/CallScribe.app`.

Разрешение «Запись экрана» нужно и для видео, и для системного звука — так устроен ScreenCaptureKit. Без него macOS не отдаёт ни экран, ни звук из других приложений.

> Приложение подписано ad-hoc, но с постоянным designated requirement по bundle ID, поэтому после пересборки разрешение обычно сохраняется. Если macOS всё же попросит выдать его заново — просто повторите шаги выше. Для стабильных разрешений приложение должно запускаться из `/Applications`.

## Как пользоваться

1. Нажмите на иконку в строке меню.
2. Выберите **«Записать звонок (аудио)»** или **«Записать экран (видео)»**.
3. По окончании нажмите **«Остановить запись»**.
4. Дождитесь расшифровки. Готовый текст появится в папке расшифровок.

По умолчанию всё лежит здесь:

```
~/Documents/CallScribe/
├── Recordings/     # .m4a (звонок) или .mov (экран), плюс .mic.m4a при записи микрофона
└── Transcripts/    # .txt и, если включено, .srt
```

Папку можно поменять в настройках. Там же выбираются модель, язык, микрофон, авто-расшифровка и таймкоды.

## Почему две дорожки

При записи звонка создаются два файла:

- `2026-11-03_10-00-00_call.m4a` — **системный звук**, то есть голос собеседника и всё, что звучит в наушниках/колонках;
- `2026-11-03_10-00-00_call.mic.m4a` — **микрофон**, то есть ваш голос.

Они пишутся раздельно, потому что захватываются разными системными API. Так их можно точно выровнять по времени, не потерять качество и не получить эхо. Whisper внутри приложения смешивает обе дорожки автоматически — для расшифровки ничего делать не нужно.

## Отправить в другой сервис

Внешнему сервису обычно нужен один файл, поэтому в меню есть пункт **«Сделать один аудиофайл (.wav)»**: он смешивает системный звук и микрофон в `..._mixed.wav` (16 кГц, mono, PCM 16 бит — стандартный формат для распознавания речи) и показывает файл в Finder.

То же самое из терминала:

```bash
.build/release/callscribe-cli mix \
  ~/Documents/CallScribe/Recordings/2026-11-03_10-00-00_call.m4a \
  --mic ~/Documents/CallScribe/Recordings/2026-11-03_10-00-00_call.mic.m4a \
  --out ~/Desktop/call.wav
```

Если запись видео (`.mov`), можно передать её как основной файл — аудиодорожка извлечётся автоматически.

### Модели

| Модель | Размер | Когда выбирать |
|---|---:|---|
| Whisper large-v3 | 626 МБ | Максимальная точность, рекомендуется для русского |
| Whisper large-v3 turbo | 632 МБ | Почти такая же точность, но быстрее |

Модель скачивается при первом использовании (или кнопкой «Скачать сейчас» в настройках) и хранится в:

```
~/Library/Application Support/CallScribe/Models/
```

Можно пользоваться офлайн после первой загрузки.

Первая загрузка модели в память занимает около 1–2 минут: Core ML компилирует модель под ваш чип. Приложение начинает готовить модель заранее, как только стартует запись, поэтому обычно к концу звонка она уже готова. В рамках одного запуска приложения повторные расшифровки идут быстро.

## CLI

В комплекте есть утилита для пакетной расшифровки:

```bash
.build/release/callscribe-cli transcribe запись.m4a --out ~/Desktop/расшифровка.txt
.build/release/callscribe-cli transcribe видео.mov --language ru --timestamps --srt
.build/release/callscribe-cli models
```

Опции: `--model`, `--language ru|auto`, `--out`, `--timestamps`, `--srt`, `--quiet`.

Запись без UI (диагностика):

```bash
.build/release/callscribe-cli record --seconds 10
.build/release/callscribe-cli record --video --seconds 5
```

## Как это устроено

- **UI** — SwiftUI `MenuBarExtra`, без Dock-иконки (`LSUIElement`).
- **Захват** — `ScreenCaptureKit` для экрана и системного звука, `AVCaptureSession` для микрофона.
- **Файлы** — `AVAssetWriter`: `.mov` с H.264 + AAC для видео, `.m4a` для аудио. Дорожка микрофона пишется отдельно, чтобы потом аккуратно смешать её с системным звуком по меткам времени.
- **Расшифровка** — WhisperKit (Core ML, large-v3) локально. Аудио декодируется в 16 кГц mono через `AVAssetReader`, дорожки микшируются, затем распознаются.
- **Текст** — сегменты Whisper собираются в абзацы по паузам; опционально сохраняются таймкоды и SRT.

## Ограничения

- Нет разделения по говорящим (диаризации). Обе стороны звонка попадают в один текст.
- Если слушать звонок через динамики, микрофон запишет и голос собеседника — будет эхо. **Лучше использовать наушники.**
- Приложения с защищённым аудио (некоторые плееры/DRM) могут не отдавать звук через ScreenCaptureKit.
- Очень длинные записи (несколько часов) занимают много памяти при декодировании. Для часовых созвонов всё нормально.
- Нет нотаризации Apple Developer ID: приложение предназначено для локальной сборки и личного использования.

## Разработка

```bash
swift build                 # debug
swift build -c release      # release
./scripts/build-app.sh      # собрать .app
```

Логи: `~/Library/Logs/CallScribe.log`.

## Приватность

Приложение не отправляет аудио, видео или текст на серверы. Единственный сетевой запрос — загрузка модели Whisper с Hugging Face при первом использовании. Дальше всё работает офлайн.
